# PV 大题实验室

[在线学习](https://futabaly.github.io/os/pv-lab/) · [项目说明](../../README.md) · [来源清单](../../docs/sources.md)

先在知识点中区分同步、互斥和容量，再用交互调度器观察阻塞与唤醒。真题页按年度选择，先写草稿，再展开参考解法；最后用速查页复习。

支持深链接，例如 `#exam-2025` 直达植树题、`#lab` 进入实验、`#summary` 打开公式页。草稿仅在本地浏览器保存，换设备不会同步。

## 代码展示

交互推导底部按当前模型生成完整英文伪代码，容量初值与演示同步；死锁模型明确标为错误示例。历年真题代码使用英文标识符与英文注释，中文关系分析保留在代码外。参考实现由本站整理，不标为官方标准答案。
