# 操作系统：让电脑协同工作的幕后系统

规格：1920 × 1080，30 fps，159 秒。黑底、荧光绿、悬浮界面、粒子与流程动画。

音频：按用户要求直接使用提供的《Vibe知识大赏｜GitHub.m4a》，不改写、不克隆声音。音频与操作系统画面的主题可能不同，画面文字为独立知识说明，不是音频转写字幕。

原始 M4A 保存在 `public/original-audio.m4a`；预览使用同一内容解码得到的 `public/preview-audio.wav`，便于浏览器兼容播放。首次播放请点击播放器的播放按钮，让浏览器启用音频。

## 分镜

| 时间 | 画面 | 要表达的知识 |
| --- | --- | --- |
| 00:00–00:16 | 软件围绕 OS 核心运动，计算机从硬件组件变成整体 | 操作系统是管理硬件资源、为应用提供服务的系统软件 |
| 00:16–00:35 | 应用、系统、硬件三层展开，光点沿请求路径移动 | 应用借助操作系统使用硬件；内核是系统的核心部分 |
| 00:35–00:57 | 三个任务排队，CPU 时间片依次点亮 | 单核上快速切换任务形成并发；多核还能并行执行 |
| 00:57–01:18 | 程序从磁盘装入内存，内存区域分配给不同进程 | 内存是运行时工作区，通常断电丢失；磁盘用于持久保存 |
| 01:18–01:39 | 编辑内容通过保存路径写入文件系统与磁盘 | 文件系统组织文件与目录；保存操作让数据进入持久存储流程 |
| 01:39–02:00 | 键盘输入经过驱动、系统抵达应用，内容显示到屏幕 | 驱动帮助操作系统与具体设备沟通 |
| 02:00–02:21 | 普通应用被隔离，文件访问经过权限检查 | 权限与进程隔离限制访问，但不代表绝对安全 |
| 02:21–02:39 | 多种操作系统名称围绕同一资源管理核心 | Windows、macOS、Linux、Android、iOS 都承担资源管理和服务应用的角色 |

## 预览

在此目录运行 `npm run dev`，选择 `OperatingSystem`。`Scenes` 文件夹可以单独预览每段动画。

用户明确要求导出时，可运行：

```sh
npx remotion render src/index.ts OperatingSystem operating-system.mp4
```

CPU 时间片、内存分区、文件写入路径均为入门示意，不代表具体系统的精确实现。
