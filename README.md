# OS · 操作系统可视化实验室

**[网站首页](https://futabaly.github.io/os/)** · **[PV 大题专题](https://futabaly.github.io/os/pv-lab/)**

按 [数字编码实验室](https://futabaly.github.io/co/digital-encoding/) 的学习形式制作：**知识点 → 交互推导 → 历年真题 → 公式与速查**。后续专题继续使用这一结构，约定保存在 [AGENTS.md](AGENTS.md)。

## 第一个专题：PV 操作大题

- 知识点：互斥、同步、计数与记录型信号量的 P/V 语义。
- 7 个交互模型：生产消费、错误加锁顺序、博物馆、哲学家与碗、两线程前驱、一次写读、植树流水线。
- 支持逐进程单步、轮询调度、自动演示、回退和重置；实时显示信号量、阻塞队列、动作位置和执行轨迹。
- 2009—2026 年连续年份索引，收录 **11 道 PV 设计大题 + 2 道互斥原理分析大题**。五个无相关大题的年份明确标记，未虚构题目补齐。
- 每题含题意概述、来源链接、信号量表、分步分析、参考伪代码、易错点及一道本站自编知识检查。
- 自由书写草稿、掌握标记保存在当前浏览器；展开参考方案进行主观题自查，不提供虚假的自动阅卷分数。
- 公式附适用条件，支持打印速查页。

## 真题范围与来源

本版只做 **PV／同步互斥相关综合应用大题**，不是操作系统全部题库，也不包含全部选择题。年份使用试卷年份（例如 2026 年试卷）；截至 2026-10-14 已核对到 2026。

题意以简述呈现，不整卷转载；参考解法为教学推导，非官方评分标准。逐年来源及关键说明见 [来源与年度清单](docs/sources.md)。原题图示涉及的前驱约束已用文字说明；有不同编排的转载以题号和题意共同定位。

交互区是代表模型，并非每道题的逐行仿真。2013 的容量缩小供演示，2019 固定 5 位哲学家，2021 与 2023 为原理题；这些区别在页面中说明。

## 本地运行

Node.js 22+，零 npm 依赖：

```sh
npm run check
npm run build
python -m http.server 8000 --directory dist
```

打开 <http://localhost:8000/pv-lab/>。页面使用 ES modules，需通过 HTTP 服务访问。CSS、JavaScript 全部本地提供，不依赖外部字体或 CSS CDN；来源链接需要网络。

## 项目结构

```text
projects/pv-lab/
  index.html       四栏目学习界面
  style.css        响应式布局与打印样式
  engine.js        可测试的记录型信号量调度器
  questions.js     年份索引、题意、参考解法与来源
  app.js           交互、草稿保存和深链接
scripts/build.mjs  生成首页与实验页面
tests/engine.test.mjs  调度不变量、反例与题库结构验证
docs/sources.md    年度清单与来源说明
```

每次推送 `main`，GitHub Actions 自动测试、构建并发布 Pages；PR 仅检查和构建。

测试包含记录型信号量计数守恒、等待队列一致性、容量约束、指定死锁反例、前驱全部有限调度与固定种子的交错调度。通过有限测试不等同于对任意调度下的无饥饿性证明。
